# 8-BIT TRACKER · WebAudio 芯片编曲器

Web 端 8bit 编曲工具(简化版库乐队):多音轨 + 步进音序器,全部声音由 WebAudio 实时合成(NES APU 风格),**不使用任何音频素材文件**。

## 运行

```bash
npm install
npm run dev        # 打开终端给出的地址(默认 http://localhost:5173)
```

构建与检查:

```bash
npm run build      # tsc -b && vite build
npx tsc --noEmit -p tsconfig.app.json
```

## 使用说明

1. 打开页面后点击 **▶ PRESS START**(创建/恢复 AudioContext,浏览器手势要求),内置示例曲已在工程中;
2. 点 **▶ PLAY** 播放(内置循环),播放列高亮实时跟随、**视口自动跟随播放头**(循环回绕自动滚回开头);**BPM 用 − / + 或直接键入(40–240,越界自动钳位)**,**BARS 用 − / + 步进或直接键入任意整数(1–64 小节,上限源于离线渲染内存)**,播放中改即时生效;
3. 左侧选择轨道,在网格上:**点空格放置 → 点音符选中(黄色实线框)→ 拖动移位 / 右缘改长 → Backspace / Delete 删除选中、右键快捷删除**;**点击标尺任意步**可自由移动光标(标尺三角指针 + 全高列光标常驻显示当前位置,默认在第 1 小节起始;播放时该列即绿色播放头,停止后回弹光标步,录制时变红);**播放中锁定编辑**(网格手势与键入写入均无效,只试听);
4. **键盘高效输入**(tracker 键位):方向键移动黄色光标(Shift+左右 = ±4 步),`Z`–`I` 字符键在光标处写入音符并自动前进一格,`[` `]` 调整写入时值(鼠标放置共用),Backspace 删除;
5. **框选与剪贴板**:**Shift + 空白处拖拽** 框选一段范围(品红虚线框);`Ctrl/Cmd+C` 复制框内音符(**无框选时复制整轨**)、`Ctrl/Cmd+X` 剪切框内音符、`Ctrl/Cmd+V` 粘贴到当前选中轨的光标处(**跨轨复制粘贴**:框选 Lead 乐句 → 选 Harmony 轨 → Ctrl+V,相对偏移保持;连续 Ctrl+V 依次后移框宽铺段落);粘贴与现有音符同格则替换、异格共存;音高越界跳过、越过轨尾丢弃;框选存在时 Backspace / Delete **批量删除**框内全部音符;顶栏 **EDIT▾** 菜单中 COPY / CUT / PASTE 等效(鼓轨暂不支持框选复制粘贴);
6. **底部键盘双模式**:默认**编辑模式**(点琴键/鼓垫试奏,鼠标操作网格);点右下角 **● REC** 进入**录制模式**——先倒数 1 小节(光标在起始步闪烁、每拍一声计数),随后光标变红色实线框按 BPM 自动步进(16 分音符),点琴键/鼓垫(或 `Z`/`Q` 行、鼓轨 `Z/X/C/V`)即写入**光标当前步**,音符与鼓机同时生效;**长按琴键持续发声,松手按持按步数定稿时值**(短按 = 16 分音符);再点 REC 退出;
7. **PLAY 从光标处开始播放**;播放与编辑/录制互斥:开播自动退出 REC、开 REC 自动停播放,播放中只试听不写入;
8. **撤销 / 重做**:顶栏 **EDIT▾** 菜单中 **UNDO / REDO**(带快捷键提示),或 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z`(重做也可 `Ctrl+Y`);任何编辑(音符、BPM、小节数、音量、导入工程、DEMO/NEW)都可逐步回退,上限 100 步;
9. 鼓轨显示为 4 行鼓机(Kick 红 / Snare 黄 / Hi-hat 青 / Crash 品红),点击开关;
10. 底部键盘或电脑键位单按试奏当前轨音色;
11. 每轨:**VOL** 音量、**M** 静音、**S** 独奏;Pulse 轨可切 12.5% / 25% / 50% 占空比;
12. **FILE▾ 菜单**:SAVE / LOAD JSON 导出导入工程;EXPORT WAV 离线渲染整曲(循环 2 遍 + 尾音)下载 16bit PCM;DEMO / NEW 恢复示例曲 / 清空;
13. 任何改动防抖 800ms 自动保存到 localStorage,刷新页面自动恢复;**DEMO / NEW** 恢复示例曲 / 清空。

### 快捷键

| 键 | 作用 |
| --- | --- |
| `Z S X D C V G B H N J M ,` | 音轨:在光标处写入 C3 八度音符(S/D/G/H/J 黑键);单按也可试奏 |
| `Q 2 W 3 E R 5 T 6 Y 7 U I` | 写入 C4 八度(高八度) |
| `方向键` | 移动写入光标(Shift+左右 = ±4 步) |
| `[ / ]` | 调整写入时值(编辑模式写入与鼠标放置共用;REC 录制为长按时值) |
| `Backspace / Delete` | 框选存在:批量删除框内全部音符;否则删除光标处音符(即点选的音符);打字流中 Backspace 回退一格删除 |
| `Shift + 空白拖拽` | 框选一段范围(品红虚线框);位移不足 1 格视为清除 |
| `Ctrl/Cmd + C` | 复制:框内音符(无框选时复制整轨);鼓轨为空操作 |
| `Ctrl/Cmd + X` | 剪切框内音符(无框选为空操作) |
| `Ctrl/Cmd + V` | 粘贴到当前轨光标处(同格替换、异格共存;越界音高跳过、越过轨尾丢弃) |
| `Ctrl/Cmd + Z` | 撤销(输入框聚焦时不劫持,走文本撤销) |
| `Ctrl/Cmd + Shift + Z` 或 `Ctrl + Y` | 重做 |
| `ESC` | 清除框选;再取消选中;均无时停止播放 |
| `Z / X / C / V`(鼓轨选中时) | 试奏 Kick / Snare / Hi-hat / Crash;REC 录制模式写入光标当前步(只加不删) |
| `SPACE` | 播放(从光标步开始)/ 停止;播放中编辑锁定,只试听 |
| `● REC`(右下角) | 录制模式开关(与播放互斥):倒数 1 小节后,光标按 BPM 自动步进,琴键/鼓垫/键位写入落在光标当前步,长按按时值定稿 |

## 移动端

单代码库响应式,平板 / 手机 / 桌面同一页面:

- **≤1024px**:轨道面板变为左侧抽屉(默认收起),工具栏 **☰** 开合、点背板关闭;网格占满全宽;
- **≤640px**:工具栏为 OS 菜单栏紧凑单行(标题缩写 8BIT + FILE/EDIT 菜单 + ▶/■ + ● REC + BPM/BARS 输入框),编辑与文件操作均在菜单内,无折叠按钮;
- **触控手势**:网格空格**单指滑动 = 滚动**,**tap = 放置**(鼓格同理开关);点音符直接拖动移位 / 右缘改长,多指只跟踪第一根;
- **WRITE 模式**:虚拟键盘上方开关,开启后点琴键/鼓垫即写入光标处并前进一格(品红描边提示),配合方向键定位可在手机上完成 tracker 式输入;
- **键盘区可收起**:给网格让出屏幕空间;
- **适配细节**:100dvh 动态视口、iPhone 刘海/横条安全区(env(safe-area-inset-*))、无点按高亮;
- **PWA**:manifest + 图标齐全,浏览器"安装到主屏"后以 standalone 打开(theme 背景同色无白边)。

## 架构

- `src/audio/` — 音频引擎(纯 TS 单例,与 React 完全解耦):`engine`(Context 生命周期/母线/试奏)、`scheduler` + `scheduler.worker`(lookahead 调度 + 视觉队列,心跳定时器跑在 Web Worker 里,后台标签页不掉拍;Worker 不可用时降级主线程定时器)、`instruments`(脉冲波 PeriodicWave、三角 bass、噪声鼓组)、`exporter`(OfflineAudioContext 渲染 + WAV 编码)
- `src/state/` — 数据模型 + zustand store + localStorage 持久化
- `src/components/` — Toolbar / TrackPanel / Grid / Keyboard / Toast / BootOverlay(CSS Modules 像素风)
- `src/song-demo.ts` — 内置示例曲:TETRIS A 主题《Korobeiniki》8 小节改编(公有领域民歌,非任天堂原版音频/谱面)

## 已验证

- `tsc --noEmit` 与 `npm run build` 通过
- 浏览器实测:播放节拍稳定(120 BPM 下播放头 125ms/步)、列高亮正确移动、console 无报错
- 撤销/重做:音符写入/删除、BPM/小节数、DEMO/NEW、导入工程逐步回退与重做正确;按钮 disabled 态、输入框聚焦不劫持、undo 后播放内容与自动保存同步生效
- 播放头自动滚屏:8 小节播放视口持续跟随(右侧保持 4 格余量),循环回绕时 scrollLeft 归零滚回开头
- BPM 输入框:键入 768 钳到 240,清空不崩溃不误跳
- 调度心跳来自 Web Worker(页面加载 `scheduler.worker.ts` 独立 chunk,start/stop 消息协议实测);播放中面板遮挡 ≥10s,返回后播放头无大步跳跃、步进均匀连续
- 工程 JSON 导出→导入 round-trip 数据一致(sanitize 幂等,两轮验证)
- 移动端实测(375/390/768/1280 视口):布局不破、无整页横滚;抽屉/⋯菜单/键盘收合可用;触控 tap 放置、滑动零误放、音符拖拽、鼓格开关、WRITE 写入全过;桌面鼠标行为回归一致;manifest 与图标可访问、console 无报错
- 导出 WAV 可解码、非静音(16bit/44.1kHz/双声道,峰值 0.7+)
- 鼓组 4 件(Kick / Snare / Hi-hat / Crash),小节数 1–64 任意整数(缩小自动丢弃范围外音符,旧存档兼容)

## 已知限制

- 后台播放依赖调度心跳 Worker;Worker 被环境禁用而降级为主线程定时器时,后台标签页仍会被节流掉拍(前台无差别);
- ≤640px 琴键区超宽时容器内横向滑动(黑键定位为 JS 常量,不在窄屏改键宽;白键禁 flex 收缩保证黑白键对齐);320px 极窄屏工具栏两行;
- iOS 真机 WebAudio 行为(切换后台挂起恢复)已按 visibilitychange 处理,但未在真机回归;
- 小节数上限 64:WAV 导出需整曲一次性离线渲染,内存与文件体积随长度线性增长;
- 网格音高固定 C3–C5(Triangle Bass 写 C3 区、实际发音低八度 C2 区);
- 需要 Chrome / Edge / Firefox / Safari 等现代浏览器(支持 WebAudio、Pointer Events 与 Web Workers)。
